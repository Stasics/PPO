## Как смотреть диаграммы

Диаграммы написаны на **Mermaid** и видны прямо в GitHub, VS Code, Notion, Obsidian.

Нужны картинки — откройте <https://mermaid.live>, вставьте код и скачайте PNG/SVG.
Локально: `mmdc -i diagrams/01-use-case-diagram.mmd -o diagram.png -b white`
