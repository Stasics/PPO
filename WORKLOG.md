## Принятые решения

| № | Решение | Почему |
|---|---------|--------|
| 1 | Сервер — источник истины, браузер только показывает | Иначе две вкладки разойдутся |
| 2 | Позиция карточки — по версии, текстовые поля — last-write-wins | Порядок карточек смешать нельзя |
| 3 | WIP-лимит блокирует перемещение, но не создание карточки | Иначе нельзя завести задачу в перегруженной колонке |
| 4 | Гость по ссылке никогда не меняет структуру | Публичная ссылка не должна утекать в редактирование |
| 5 | Падение GitHub не блокирует работу карточки | Внешняя система не должна останавливать команду |
| 6 | Журнал событий только дополняется, ничего не удаляется | Достоверность истории важнее экономии места |
| 7 | Модель: пространство → доска → колонка → карточка | Позволяет переиспользовать структуру и права |
| 8 | Спринт и эпик не моделируются | Не нужны для ценности продукта |
