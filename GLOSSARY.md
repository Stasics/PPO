# Словарь терминов

Короткий указатель для защиты. Полный разбор — в
[docs/04-domain-model.md](docs/04-domain-model.md).

| Термин | Значение |
|--------|----------|
| **Доска** (Board) | Одна рабочая доска: колонки, карточки, участники |
| **Пространство** (Workspace) | Контейнер верхнего уровня: несколько досок и участников |
| **Колонка** (Column) | Статус или этап на доске |
| **Финальная колонка** | Колонка «Готово»; карточка в ней заблокирована |
| **Карточка** (Card) | Единица работы: задача, дефект, идея |
| **Шаблон** (Template) | Заготовка колонок: Scrum, Kanban, воронка |
| **WIP-лимит** | Максимум карточек, который можно держать в колонке |
| **Исполнитель** | Ответственный за карточку, 1–5 человек |
| **Наблюдатель** | Следит за карточкой, получает уведомления, не отвечает |
| **Метка** (Label) | Цветной тег карточки |
| **Приоритет** | CRITICAL / HIGH / MEDIUM / LOW |
| **Drag & drop** | Перетаскивание карточки мышью |
| **Присутствие** (Presence) | Кто онлайн на доске и где его курсор |
| **Комментарий** | Обсуждение под карточкой |
| **@упоминание** | Обращение к участнику в комментарии |
| **Уведомление / дайджест** | Личное сообщение о событии / сводка за день |
| **Лента активности** | Хронология событий всей доски |
| **История изменений** | Что менялось в одной карточке: «было → стало» |
| **Версия** | Счётчик изменений карточки — защита от потери правок |
| **Оптимистичная блокировка** | Проверка версии перед записью, без долгой блокировки |
| **Гостевая ссылка** | Ссылка для посетителя без регистрации |
| **Интеграция** | Подключение к GitHub или Jira |
| **BR / FR / NFR / UC / US** | Бизнес-правило / функциональное / нефункциональное требование / прецедент / пользовательская история |

## Синонимы, которые стоит знать

| Слово | В нашей системе это |
|-------|---------------------|
| Задача, тикет, issue, story | **Карточка** |
| Спринт, эпик, story point | Отдельных сущностей нет — это метки или просто не моделируется |
| Workflow, бэклог спринта | **Колонки доски** |
| Kanban | Метод; **доска** — инструмент, где он реализован |

## Частые вопросы и короткие ответы

| Вопрос | Ответ |
|--------|-------|
| Почему решает сервер, а не браузер? | Иначе две вкладки разойдутся: «побеждает тот, кто дольше держал мышь» (BR-08) |
| Что такое WIP-лимит простыми словами? | «Не бери больше, чем успеваешь доделать»: колонка не примет лишнюю карточку (BR-06) |
| Чем гость отличается от участника? | У гостя нет учётной записи, только токен ссылки с уровнем «чтение» (BR-10) |
| Что будет, если упал GitHub? | Карточка сохранится, синхронизация повторится позже (BR-13) |
| Где хранится история? | Журнал событий, append-only, хранение 90 дней (BR-12) |
