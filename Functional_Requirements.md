# Функциональные требования (FR) — Boardline

**Роли:** Гость (неавторизованный пользователь), Пользователь (авторизованный), Участник (имеет доступ к доске), Редактор, Наблюдатель (Viewer), Владелец доски, Администратор.

**Формат ID:** `FR-<номер UC>.<порядковый номер>`. В колонке «Источник» указан AC, из которого выведено требование.

---

## UC-01, UC-02. Регистрация и вход

| ID | Требование | Источник |
|---|---|---|
| FR-01.1 | Система должна предоставлять Гостю форму регистрации по email и паролю. | User Story |
| FR-01.2 | Система должна проверять уникальность email при регистрации. | AC 1 |
| FR-01.3 | Если email уже зарегистрирован, система не должна создавать аккаунт и должна выводить сообщение: «Пользователь с таким email уже существует. Войдите или восстановите пароль». | AC 1 |
| FR-02.1 | Система должна предоставлять форму входа по email и паролю. | User Story |
| FR-02.2 | При вводе корректных учетных данных система должна аутентифицировать пользователя и перенаправлять его на страницу «Мои доски». | AC 2 |
| FR-02.3 | Поле «Пароль» должно скрывать вводимые символы (маскирование). | AC 3 |
| FR-02.4 | При неверных учетных данных система должна выводить обобщенное сообщение «Неверный email или пароль», не уточняя, что именно введено неверно. | AC 3 |
| FR-02.5 | Система должна хранить пароли только в виде хеша (bcrypt). | NFR |
| FR-02.6 | Система должна предоставлять возможность восстановления пароля (ссылка из сообщения об ошибке FR-01.3). | AC 1 |

| ID | Требование | Источник |
|---|---|---|

| FR-07.4 | При изменении размера фигуры с зажатой клавишей Shift система должна сохранять пропорции (круг, квадрат). | AC 3 |
| FR-07.5 | Шрифт текстового блока должен визуально адаптироваться под текущий масштаб холста. | AC 3 |
| FR-07.6 | Система должна позволять размещать объекты внутри фрейма путем перетаскивания в его границы. | AC 4 |
| FR-07.7 | Объект, помещенный во фрейм, должен привязываться к нему и перемещаться вместе с фреймом. | AC 4 |
| FR-07.8 | Система должна позволять перемещать стикеры, фигуры и текст (Drag & Drop) мышью и тач-жестами. | AC 5 |
| FR-07.9 | Система должна поддерживать загрузку изображений форматов PNG и JPG размером до 10 МБ с сохранением оригинальных пропорций. | AC 5 |
| FR-07.10 | Панорамирование и масштабирование холста не должны изменять взаимное положение объектов. | AC 5 |
| FR-07.11 | Редактирование объектов (создание, изменение, перемещение, удаление) должно быть доступно только пользователям с ролью «Редактор» и выше. | AC 1, UC-03 AC 1 |

| FR-09.10 | При закрытии вкладки пользователем его курсор должен исчезать у остальных участников в течение 5 секунд. | AC 4 |
